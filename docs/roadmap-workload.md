## 分档明细

### 阶段 0 · 需求冻结（S）— 已基本完成
- **产出**：本基线 + 拍板记录。
- **卡点**：C1（JoyGen）。

### 阶段 1 · 前端模板初始化（S）
- 固定模板 commit、确认 Node 22、清理演示页（dashboard/form/list/profile/account/chatbot 只留登录 + 3 业务入口）。
- **坑**：`npm run simple` 不可逆，清理前先 commit（AGENTS.md）。
- **门禁**：`npm run lint` + `npm run tsc` + `npm run build` 通过。

### 阶段 2 · 系统骨架与路由（M）
- 路由：`/contracts/new`、`/approvals`、`/ledger`、`/exports`、`/admin`。
- 通用组件：StatusTag / ApprovalTimeline / AmountDisplay / FileList / 确认弹窗 / 空态 / 加载态。
- 前端类型：User/Department/Contract/ContractItem/ApprovalInstance/Node/Task/AuditLog/ExportJob（金额=十进制字符串）。
- **门禁**：路由刷新不丢页、菜单按角色、无散落请求逻辑、tsc 通过。

### 阶段 3 · 数据库 + 后端基础框架（M）
- NestJS 初始化（CORS / 前缀 `/api/v1` / requestId / 全局异常 / Pino 日志 / Health）。
- Prisma Schema（PRD §10.2 全表 + §10.3 约束 + 唯一索引）。
- 迁移 + 种子（≥2000 条历史单据）+ 测试库。
- **最高返工风险**：schema 务必对齐「审批链/审批记录分表 + 审计字段 + DECIMAL + 索引」。
- **门禁**：干净环境可重复迁移、约束正确、健康检查、无硬编码密码。

### 阶段 4 · 身份认证 + 权限体系（M，重点）
- 登录/登出/me、密码哈希、禁用账号、认证失效。
- 角色表 + 用户角色 + **权限 Guard + 数据范围校验**。
- 初始化 6+ 测试账号（员工/主管×2/法务/财务总监/管理员/审计员）。
- 越权测试先行（R01–R08）。
- **门禁**：未登录→401/403；员工看不了他人；审批人动不了他人任务；禁用账号失效；**此阶段不过不进业务开发（PRD §4）**。

### 阶段 5 · 合同申请 + 文件上传（M–L）
- 申请人/部门只读（后端给）；原因/紧急度校验。
- 动态明细（稳定行 ID、禁数组下标、删行不串行、金额不重复计）。
- 保密协议联动（前端 + 后端同规则）。
- 附件：上传接口 + 大小/PDF 内容校验 + 私有存储 + 未引用清理。
- 用 **EditableProTable**（模板 advanced-form 现成模式）。
- **门禁**：PRD §14.1（金额边界）+ §14.2（文件）全过。

### 阶段 6 · 审批链快照 + 提交事务（L）
- 规则服务：金额分段 + 岗位映射 + 快照生成。
- 提交事务：身份/明细/附件/金额重算/快照/首个任务/审计 **同一事务**。
- 幂等：防重复提交（幂等键）。
- **门禁**：PRD §14.1 A01–A10 全过；找不到审批人提交失败；无半成品；重复点击不重复建单。

### 阶段 7 · 审批中心 + 完整状态机（L，最重）
- 待办/已办列表（按登录人 ID 查，不信前端参数）。
- 同意 / 驳回 / 转交 / 加签 / 撤回 / 强制终止，全部**事务 + 条件更新/乐观锁**。
- 终态：前端按钮不进 DOM + 后端拒绝。
- **门禁**：PRD §14.3 P01–P10（并发同意仅一次成功）+ §14.4 R01–R08 全过。

### 阶段 8 · 台账 + 脱敏 + 附件安全下载（M）
- 组合查询（编号/申请人ID/类型/状态/金额区间/时间区间）+ 分页排序 + 排序字段白名单 + SQL 参数化。
- URL Query 同步与恢复（`/ledger?...`，前进后退还原，空值不入 URL）。
- 脱敏：统一社会信用代码 `9131**********ABCD`、银行账号 `6222 **** **** 4567`，**服务端统一规则**，日志/导出同步脱敏。
- 附件二次鉴权：`POST /api/v1/files/:id/download-url` 短时效签名。
- **门禁**：普通用户进不了台账；未授权拿不到附件；脱敏格式一致。

### 阶段 9 · 异步 Excel 导出（M–L）
- 任务表 + Worker；分批游标读取 + ExcelJS 流式写入；OOM 防御。
- 审计字段（操作人/筛选快照/条数/耗时/状态/文件/失败原因/过期时间）。
- 前端 Loading 防重 + 刷新恢复状态 + 下载前重鉴权。
- **门禁**：PRD §14.5 E01–E08（1万/10万导出、重复点击幂等、刷新恢复、过期拒绝、条数正确）。

### 阶段 10 · 联调 + 测试 + 安全验收（M）
- 自动化接口测试套件（Supertest）：正常三级审批流 + 越权 403 + 状态翻转边界 + 审计断言 + 脱敏断言。
- 端到端 Playwright 主流程。
- **门禁**：核心测试 100% 通过、无阻断缺陷、无高危越权、构建/tsc 通过。

### 阶段 11 · 部署 + 交付（M）
- Docker Compose（PG + 文件目录）+ 迁移 + 构建 + 冒烟。
- README 五步启动（评审 5 分钟跑通）+ API 文档 + 测试报告 + 账号矩阵。
- **分支**：C1 定了 → JoyGen（免自部署）或自部署 + 访问链接。

## 关键依赖顺序（不可跳)

```
0 需求冻结 → 1 模板清理 → 2 骨架路由 → 3 DB/后端框架 → 4 认证权限
   → 5 申请+文件 → 6 快照+提交 → 7 审批状态机 → 8 台账脱敏下载
   → 9 导出 → 10 联调测试 → 11 部署交付
```

阶段 3 schema 与阶段 4 鉴权是**地基**，前面没稳后面必返工；阶段 7（状态机）与阶段 9（导出）是两个**最重**节点，建议各拆成多个小 change 分步 apply + 验收。
