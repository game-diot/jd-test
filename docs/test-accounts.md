## 审批链路（金额三档 → 节点 → 审批人）

| 金额区间 | 审批链 | 节点审批人 |
|---|---|---|
| < 50 万 | 部门主管 | 申请人所属部门 `departments.manager_user_id`（IT=李主管） |
| 50 万 ≤ x < 200 万 | 部门主管 → 法务 | 主管 + `approval_position` LEGAL_REVIEW（赵法务） |
| ≥ 200 万 | 部门主管 → 法务 → 财务总监 | + CFO（钱总监） |

## 一键初始化

```bash
cd server
npm run prisma:migrate          # prisma migrate dev
npm run prisma:seed             # 基础账号/部门/岗位
npm run prisma:seed:history     # 2000 条历史单据（金额/信用代码/银行账号）
```
