## 3. 角色与岗位模型

**两套正交维度，不可混为一谈：**

- **角色（role）**：普通员工 / 审批人 / 系统管理员 / 合规审计员 /（开发测试专用）。
- **审批岗位（approval_position）**：部门主管 / 法务审批 / 财务总监 —— 独立于角色，是审批链节点上「由谁来批」的映射来源。

一个用户可多角色、可任多岗位；多角色合并后**仍受数据范围约束**（最小权限，默认拒绝）。

### 角色权限矩阵（功能 ∩ 数据范围）

| 功能 | 普通员工 | 审批人 | 系统管理员 | 合规审计员 |
|---|---|---|---|---|
| 创建申请 | ✅ | ✅（兼员工身份时） | 按需 | ❌ |
| 查看本人申请 | ✅ | ✅ | ✅ | 按授权 |
| 查看他人申请 | ❌ | 仅有审批权/授权记录 | ✅ | 按审计范围（脱敏） |
| 审批（同意/驳回/转交/加签） | ❌ | ✅ 仅本人当前有效任务 | 默认 ❌ | ❌ |
| 撤回 | 符合条件时 | 符合员工+业务规则时 | 默认不开放 | ❌ |
| 强制终止 | ❌ | ❌ | ✅（必填原因） | ❌ |
| 台账查询 | ❌ | 按业务授权 | ✅ | ✅ |
| 敏感信息 | 默认脱敏 | 默认脱敏 | 默认脱敏 | 默认脱敏 |
| Excel 导出 | ❌ | 按需授权 | ✅ | ✅ |
| 审计日志查看 | ❌ | 仅自身相关 | ✅ | ✅ |

## 4. 审批人配置规则

- **部门主管**：`departments.manager_user_id`（按申请人所属部门解析）。
- **法务审批人 / 财务总监**：全局配置 `approval_positions`（可配置岗位 → 有效用户映射）。
- 找不到有效审批人 → **提交失败**，返回可理解错误；禁止自动跳过、禁止「第一个搜索到的管理员」兜底（PRD §6.2）。

## 5. 数据访问范围（水平越权边界）

**原则：身份一律取后端认证上下文（token/session），绝不信前端传的身份/归属参数。**

| 主体 | 可见/可操作范围 |
|---|---|
| 普通员工 | 仅本人提交的申请 + 本人有权访问的附件 |
| 审批人 | 仅分配**给本人**的待办 + 本人处理过的记录；附件仅限有权任务关联 |
| 系统管理员 | 全量申请单（查询）+ 终止「待审批」单；**不默认拥有审批权** |
| 合规审计员 | 台账（脱敏）+ 导出任务（本人发起的可查） |

越权拒绝统一返回 403（R01–R08，见 PRD §14.4）。

## 6. 业务规则清单（冻结）

### 6.1 审批链路由（金额三档，后端裁决）

| 合计金额（NUMERIC） | 审批链 |
|---|---|
| `< 500,000.00` | 部门主管 |
| `[500,000.00, 2,000,000.00)` | 部门主管 → 法务审批 |
| `≥ 2,000,000.00` | 部门主管 → 法务审批 → 财务总监 |

边界（PRD §14.1）：A01=499999.99→仅主管；A02=500000.00→主管+法务；A03=1999999.99→主管+法务；A04=2000000.00→三级。

### 6.2 金额规则
- DB 存 `NUMERIC(18,2)`，API 传输**规范化十进制字符串**；前端禁用 `parseFloat()` 作最终路由依据。
- 普通合同金额 > 0，最多两位小数；`0` / 负数 / 超两位小数 / 空 → 拒绝。
- 后端**重新计算合计**，忽略客户端传入的合计值与自定义审批链。

### 6.3 保密协议（NDA）联动
- 用印类型强制 `公章`，选择框仅公章；金额强制 `0.00` 且输入禁用。
- 后端拒绝：NDA 用合同章/法人章、NDA 携带非零金额。
- 普通→NDA 时清理非法金额/用印；NDA→普通时金额恢复可编辑但**不自动回填**。

### 6.4 附件
- 仅 PDF，单文件 ≤ 10 MiB；服务端校验**真实内容**（非仅扩展名/MIME）。
- 私有存储、随机对象键、原始名仅存元数据；不返回物理路径。
- 未引用附件有过期清理；删除不能动已提交引用。签名 URL 短时效 + 只读 + 限对象。

### 6.5 撤回 / 终止
- 撤回：仅「待审批」+ **首节点尚未处理**；进入第二节点即禁，错误码 `WITHDRAW_NOT_ALLOWED`。
- 终止：管理员 + 必填原因；仅「待审批」可终止；终态不可再终止。

### 6.6 终态
- 6 个申请终态：`DRAFT / PENDING_APPROVAL / APPROVED / REJECTED / WITHDRAWN / TERMINATED`。
- 已结束单据：前端**条件渲染移除操作按钮（不进 DOM）** + 后端接口拒绝一切终态操作。

## 7. 状态机

**申请单状态（6）** 与 **审批任务状态（7）** 分离，不可单字段混用（PRD §3.2）。

申请状态转换（PRD §3.3）：

| 当前 | 操作 | 目标 | 限制 |
|---|---|---|---|
| 草稿 | 保存 | 草稿 | 可改 |
| 草稿 | 提交 | 待审批 | 全量校验 + 幂等 |
| 待审批 | 同意当前节点 | 待审批 / 已通过 | 按链决定 |
| 待审批 | 驳回 | 已驳回 | 原因 ≥10 字 |
| 待审批 | 撤回 | 已撤回 | 仅首节点未处理 |
| 待审批 | 强制终止 | 已终止 | 仅管理员 + 原因 |
| 终态（通过/驳回/撤回/终止） | 任意审批操作 | 不允许 | 终态 |

任务状态：`PENDING / APPROVED / REJECTED / TRANSFERRED / WAITING_SIGN / CANCELLED / SKIPPED`。
